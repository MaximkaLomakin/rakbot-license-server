# RakBot License Server

Локальная служба-заглушка вместо мёртвого `rakbot.ru` для RakBot.
Убирает ошибку CURL #6 при запуске.

## Зачем

RakBot проверяет лицензию на `http://rakbot.ru/...`. Домен не резолвится,
libcurl возвращает ошибку 6. Служба принимает запрос на `127.0.0.1:80`,
а штатный `RakCrack.dll` подменяет ответ лицензии.

## Как работает

- `install-service.bat` добавляет в `hosts` строку `127.0.0.1 rakbot.ru`
  и ставит службу `RakLicense` с автозапуском.
- Служба слушает только `127.0.0.1:80` и отвечает на запросы лицензии.
- `uninstall-service.bat` удаляет службу и запись из `hosts`.

## Установка

1. Скачайте файлы репозитория в папку без пробелов, например
   `D:\RakBot\license`.
2. Запустите `install-service.bat` от имени администратора.

Порт 80 должен быть свободен.

Проверка:

```cmd
sc query RakLicense
ping rakbot.ru
```

Служба — `RUNNING`, `ping` — отвечает с `127.0.0.1`.

## Удаление

`uninstall-service.bat` от имени администратора.

## Сборка

`build.cmd` (Visual Studio 2022 x86) → `raklicense.exe`.
